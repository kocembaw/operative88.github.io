## work

i'm mainly interested in cloud computing and devops; combining these fields is what i'm currently focused on.

working on infrastructure and tooling has taught me many things; primarily, i have the benefit of never having learned all the reasons things are considered ‘impossible’.

## projects

- [vagus nerve stimulation research platform](/projects/vns-research-platform/), a software-only platform for browsing synthetic vns experiment data, containerised, orchestrated on kubernetes, provisioned on aws with terraform and delivered via jenkins
- [snpedia knowledge exporter](/projects/snpedia-knowledge-exporter/), a custom prometheus exporter in python that collects statistics about snpedia, deployed together with prometheus and grafana by a single ansible playbook

most of the (public) code i write these days is on [github](https://github.com/kocembaw)
